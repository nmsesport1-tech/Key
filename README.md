# Keybind Profiles (Fabric 1.21.11)

Bauen:   ./gradlew build     (Java 21 nötig)
Ergebnis: build/libs/keybind-profiles-1.0.0.jar  -> in den mods-Ordner (+ Fabric API)

Falls kein gradlew im Ordner liegt: auf https://fabricmc.net/develop/template ein leeres
Projekt für 1.21.11 erzeugen und nur den Ordner src/ sowie gradle.properties/build.gradle austauschen.

Profile liegen in .minecraft/config/keybind_profiles.json
